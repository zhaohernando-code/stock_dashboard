# R14 后续优化决策：保留现策略，不新增候选

日期：2026-07-15  
面向：产品与策略决策  
结论：本轮 7 个候选全部不晋级；前后端继续只展示当前收敛后的 3 个策略，不增加新的候选策略。

## 执行摘要

- 2025-10 在重建的 R14 基线中收益为 **+1.32%**，不是亏损月。因此，围绕该月增加“强势市场确认”不是在修复已发生的损失。
- 强势确认阈值提高到 1% 后，总收益从 **332.10%** 降到 **320.19%**，最大回撤从 **-6.89%** 扩大到 **-7.23%**，亏损月从 **2 个**增至 **5 个**，2025-10 收益也降至 **+0.57%**。
- 弱市仓位缩放中最温和的方案把最大回撤改善到 **-6.70%**，但总收益降至 **324.53%**，并新增 1 个亏损月；不满足九指标非劣化门槛。
- 当前可接受的产品决策是：**保留 R14，不新增策略、不替换策略、不改前后端策略集合**。
- 原 R14 的完整执行快照已被运行时生命周期清理。本轮 Top3 信号复现完全一致，价格锚点校验通过，但重建基线总收益仍比冻结合同低 **9.67 个百分点**。因此，本轮证据足以否决候选，但不足以晋级任何候选。

## 后续优化方案

1. **先修复可晋级的复现边界**：每次正式回放固化输入特征矩阵、候选清单、逐笔订单摘要、行情快照标识和哈希；存储治理不能再清掉唯一的晋级证据。
2. **下一轮只研究执行效率，不新增策略族**：保持 R14 信号与排序不变，分析 58 笔替补买入及现金空闲，定位哪些替补贡献收益、哪些只是成交摩擦。
3. **采用一进一出规则**：新候选只有通过相同冻结数据、相同九指标门槛并产生实质改进，才允许替换 R14；未通过的试验只留研究记录，不进入前后端候选列表。
4. **停止围绕 2025-10 做防御性调参**：该月本来盈利，现有试验证明防御门槛会伤害收益和稳定性。
