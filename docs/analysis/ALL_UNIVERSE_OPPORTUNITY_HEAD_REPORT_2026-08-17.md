# 全市场热点恢复机会头研究报告

日期：2026-08-17

结论：取消 V3 Top20 身份硬门槛能够让生益科技和长电科技及时进入候选，但无论预测平均收益还是预测热点事件，通用股票量价模型都不能稳定地把它们从大量反弹候选中排到前列。两种模型均按冻结门禁淘汰，不启动前向影子，不进入 V3、纸面追踪或前端。

## 1. 数据覆盖修正

第一次运行只使用 `ashare_hot.db`。该库虽然更新至 2026-08-14，但大部分股票在 2025 年前没有足够历史：注册回测起点 2023-09-07 只有 3 只主板股票能形成 60 日特征。由此产生的两个临时 artifact 已判定无效并删除，不能用于评价策略。

覆盖修正版保持全部模型参数和门禁不变，只修正数据源：

- `ashare_dashboard.db` 提供 2022-11-21 至 2026-07-13 的完整历史底座，注册历史日期每天约 2,900—3,000 只合格主板股票；
- `ashare_hot.db` 覆盖重复键并补充至 2026-08-14；
- 合并键为股票代码和交易日，构建过程不联网；
- 生成 32,028 条规则候选，压缩数据约 7.8 MB；
- 36 次 expanding fit 的未来标签违规均为 0。

历史 ST/特殊处理状态仍没有逐日 PIT 来源。本轮没有用当前静态状态回填历史，而是标记为未知；因此即使收益通过，也只能作为机制研究，不能直接晋级。

## 2. 机会集机制

外层使用稳定的主板代码规则、信号日未复权价格 0.01—200 元和近期个人资格快照。股票路径需同时满足：

- 最近 1 日涨幅至少 2%；
- 最近 20 日最大回撤不高于 -8%；
- 3 日收益减 5 日收益至少 3%，表示近期重新加速。

V3 Top20 历史质量只提供最多 10% 的软加分，缺少 V3 身份不会阻止股票进入候选；V3 当日现金开关也不会关闭研究机会头。

机制覆盖通过：生益科技和长电科技都在 2026-08-04 前进入机会集。说明上一轮识别出的“V3 身份硬门槛”确实会漏掉目标股票。

## 4. 热点事件分类模型

为检验是不是平均收益目标过度平滑尾部机会，第二个冻结挑战者改为预测“未来 5 日净收益至少 3%”的事件概率，保留下行风险头，其余机会集、特征、正则化、调仓频率和排序权重不变。

指定案例排名同样未通过 Top10 门禁：生益科技最好为 25，长电科技为 69。更换目标函数没有修复识别问题，反而明显恶化 Validation 和近期结果。

## 5. 机制结论与下一方向

本轮把问题缩小到了更具体的位置：

1. **机会入口确实有问题。** V3 Top20 不应继续充当热点策略的股票身份硬门槛。
2. **单一通用量价恢复模型仍不够。** 深跌后单日反弹的候选很多，股票路径可以描述“开始恢复”，但无法可靠判断哪一个会得到板块资金和新闻催化并持续成为热点。
3. **V3 不应被替换。** V3 继续承担防御型核心账户；热点机制应是受限的小型机会头，而不是每天取代 V3 的全账户策略。
4. **下一轮应研究“何时开启机会头”。** 全球状态只控制总体机会头风险预算；板块状态决定哪些行业允许竞争；个股事件只在已通过股票路径过滤后提供有界残差。正面新闻不得独立创造买入，重大官方负面事件可以关闭候选。

因此，下一项有价值的工作不再是继续扫描量价阈值或模型参数，而是补齐可回放的 PIT 板块状态、板块归属和高相关官方/新闻事件数据，然后在同一 32,028 条候选上测试“板块确认是否真正提供新增辨别力”。外部信息权重仍从 0 开始，V3 基线永久保留。
