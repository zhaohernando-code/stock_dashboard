# 热点恢复双头模型：近期 PIT 归因与淘汰报告

日期：2026-08-17
结论：本轮双头模型不启动前向影子，不进入 V3、纸面追踪、前端或运行时。它在复用历史上的 10 日结果为正，但没有覆盖要解决的快速热点恢复机制。

## 1. 证据边界

- 2026-06-29 至 2026-08-14 共 35 个交易日、106,189 个股票日，冻结为 35 MB gzip PIT 快照；构建过程不联网。
- 2026-07-08 至 2026-08-14 的 28 份逐日 V3 候选源逐份精确复现了 Top3、Top20 和现金开关；此前 7 日没有逐日归档，只能按冻结模型合同重建，不能称为已归档复现。
- 个人可交易范围在新模型打分前过滤：普通 A 股主板、非 ST、决策时点未复权价格不高于 200 元。
- 近期区间和生益科技、长电科技案例在冻结合同前已经被看过，因此全部近期结果只属于 outcome-aware 机制诊断，不是独立样本外证据。
- 强热点定义使用次日未复权收盘成交代理、45 bps 往返成本、5 日净收益至少 3%、相对基准净超额至少 2%，且位于当日超额收益前 10%。

## 2. V3 漏斗归因

可获得完整 5 日标签的 29 个信号日共有 85,542 个可交易股票日；其中 8,243 个满足强热点定义，涉及 2,076 只股票。这个分母是“每日全市场前 10% 股票日”的覆盖诊断，不是组合胜率，也不能直接与 Top3 的持仓收益比较。

| 阶段 | 强热点股票日 | 含义 |
|---|---:|---|
| V3 当日现金开关 | 4,424 | 当天整个 V3 不部署资金 |
| V3 Top20 之外 | 3,813 | 股票未进入 V3 的可排序机会集 |
| V3 Top20 但未进 Top3 | 4 | 最终排序/名额问题 |
| V3 Top3 且可执行 | 2 | 真正被现有路径覆盖 |

29 个可评估信号日中有 16 日触发 V3 现金开关。归因说明主要限制发生在市场部署开关和机会集入口，而不是 Top20 到 Top3 的最后排序。

## 3. 两个指定案例

### 生益科技（600183.SH）

- 2026-08-04 收盘信号对应次日收盘可成交，后续 5 日毛收益约 16.65%；当天 V3 触发现金开关。
- 2026-08-05 收盘信号对应次日收盘可成交，后续 5 日毛收益约 11.39%；当天未进入 V3 Top20。
- 双头模型直到 2026-08-07 才把它纳入候选，且只排 40/50：预测恢复收益为负、下行风险分位约 87.8%，已经错过要捕捉的早期恢复段。

### 长电科技（600584.SH）

- 2026-08-04 收盘信号对应次日收盘可成交，后续 5 日毛收益约 13.35%；当天 V3 触发现金开关。
- 2026-08-05 后的次日成交代理被涨停约束阻断，说明等待更强确认会迅速失去可执行性。
- 它在整个双头模型近期机会集中从未出现。下游模型无论怎样调权重，都不可能选到一个被上游硬门槛排除的股票。

## 4. 双头模型结果

模型只使用股票自身的价格、回撤、波动、均线、成交额和换手状态，以及因果可用的 V3 Top20 历史记忆。恢复头为 L2 Ridge，下行头为 L2 Logistic；11,100 条训练记录截至 2026-06-26 拟合，最晚标签可用日为 2026-06-25，未来标签违规为 0。

| 指标 | 结果 |
|---|---:|
| 近期候选股票日 | 1,750 |
| 回顾性信号 | 29 |
| 完成 5 日信号 | 25 |
| 5 日平均净收益 | -0.22% |
| 完成 10 日信号 | 20 |
| 10 日平均净收益 | +3.08% |
| 10 日胜率 | 80.0% |
| 10 日净收益中位数 | +3.00% |
| 与当日 V3 Top3 重合 | 0 |
| 指定案例机会集覆盖 | 1/2 |

正的 10 日统计不能作为晋级依据：这段数据已经被复用，而且 5 日均值为负；更重要的是，它挑到的是较慢的防御型修复，而不是本轮注册的快速热点恢复问题。结果状态固定为 `rejected_mechanism_gate_failed_no_forward_activation`，2026-08-17 前向影子启动被阻止。

## 5. 下一方向

下一轮不应继续优化这套模型的 Ridge/Logistic 权重。应先改变机会集机制：

1. 外层仍使用个人可交易资格和 PIT 未复权价格硬过滤。
2. 在全部个人可交易股票上，用纯股票路径状态筛出“下跌后重新加速、相对强度恢复、成交活跃度确认且次日仍可能成交”的候选。
3. V3 核心分数、历史入选质量和风险状态作为软特征或风险约束，不再作为股票身份硬门槛。
4. 保留防御头与机会头两套独立排序；市场状态只控制总风险敞口，不能把机会头永久关死。
5. 先冻结新合同，再做历史训练/验证；任何新的真实前向期必须从合同冻结后的首个交易日开始，历史回填不计入前向样本。

本轮产物只建立研究基础设施和淘汰证据，没有改变 V3、纸面账户、页面展示、订单或运行时。
