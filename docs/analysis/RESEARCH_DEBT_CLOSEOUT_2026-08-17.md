## 结论

本轮不是继续优化策略，而是把失败研究从主干执行面收口为“可复用基础 + 单一失败结论台账”。V3、Rank4-only 生产基线、个人资格过滤、外部数据 PIT 回放和当前四组纸面比较均保留；失败模型不再拥有可执行入口。

变更规模：删除 282 个文件，修改 8 个文件，重命名 1 个测试，新增 5 个精简文件；diff 为新增 550 行、删除 87,168 行。`docs/research` 从约 58MB 降到 7.8MB，保留的主体是 32,028 行热点机会候选数据。

## 结构修复

1. 当前纸面对照过去在模块 import 时依赖整条历史消融链。现在只依赖独立的信号注册表合同，研究生成器不再进入日刷进程。
2. 逐轮设计、结果、预测和状态重复描述被移除。Git 保存细节，主干只保留关键指标、失败机制和禁止重试条件。
3. 可复用候选数据和失败模型分离：候选数据可以承接未来板块增量检验，但回归头、分类头及其阈值不再随数据一起保留。
4. 新增 retention 测试：校验保留数据哈希、候选行数、历史 ST-PIT 缺口、外部对照注册表 PIT 合法性，并阻止已退役引擎以原名回到 runtime source。

## 明确保留而未删除

- Rank5 只保留低成本前向观测采集，因为它积累的是新未见数据；它不显示卡片、不下单、不自动重开策略。
- 外部信息公开源采集、Raw/Normalized/PIT、新闻摘要和全球/板块研究快照能力保留，因为它们是下一方向的数据基础，不是失败权重模型。
- `rolling_tranche_account_replay` 的通用账户执行能力保留；只删除依赖它的一次性挑战者。

## 剩余风险

1. 保留的热点机会候选缺少历史 ST 状态 PIT 谱系，只能用于机制研究。
2. 外部公开行情缺供应商 revision/vintage 链，公告标题缺 surprise/预期差，因此不能生产化。
3. 当前外部信息对照仍只有一次历史延期触发；需要至少 3 个独立真实前向触发。
4. 仓库仍有更早期、与本轮无关的研究模块。它们没有被本次 8 月研究引用；若未来继续做第二阶段瘦身，应按“是否仍有活跃 CLI/数据采集/运行合同”逐组审计，不能按文件名批量删除。
