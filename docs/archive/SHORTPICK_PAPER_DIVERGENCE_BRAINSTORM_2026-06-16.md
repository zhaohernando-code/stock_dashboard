# 试验田 v1/v2 纸面分歧归因脑暴记录

日期：2026-06-16

## 背景

三年历史回测中，`安静突破 Rank2 + 热度池 10% + H10 + 周一至周三 + 单笔 8.5 万` 是当前 v2 最强历史基准之一；但从 `2026-05-08` 开始的纸面追踪窗口表现较弱。用户观察到，若按 v1 选股并加上 20 万资金限制、买不起就跳过，当前窗口反而看起来更好。

## 参与视角

- 子进程：梳理 v1/v2 数据入口，指出 v1 paper ledger 是候选级 forward return，不是 20 万账户 NAV。
- Xiaomi MiMo：建议先做归因诊断，不直接调整策略；优先验证短期噪声、执行/资金约束、regime、v1 因子可吸收。
- DeepSeek：建议建立同窗对照组，包含 v2 fixed85、fixed80、v1 20w top1-or-skip、rank/fallback/回撤反转等拆分，并明确样本量不足风险。
- Codex 仲裁：采用“同窗账户路径归因矩阵”作为最小落地产物，不先改策略、不改 UI、不混用现有纸面 ledgers。

## 共识结论

1. 当前一个多月纸面弱势不能直接推翻三年历史回测，因为样本很短且 skip 率高。
2. 用户观察值得深挖：v1 与 v2 必须在同一时间窗、同一 20 万账户约束、同一整手买入规则下比较。
3. v1 原始 paper 数据只能作为候选源或 raw forward return 参考，不能直接当成 20 万账户收益。
4. v2 需要拆分 primary/fallback、资金不足/整手限制、仓位利用、尾部交易贡献，判断是否由 fallback 或集中亏损拖累。
5. 产物应是 research-only JSON + 中文摘要，后续是否改策略或 UI 要等证据。

## 建议落地产物

- 新增离线 CLI：生成 `2026-05-08` 起的纸面分歧归因 artifact。
- 输出策略对照：v2 fixed85、v2 fixed80（若数据可得）、v1 raw candidate、v1-derived 20w top1-or-skip。
- 输出归因维度：短期噪声、市场/regime、执行/资金、v1 因子重合/差异、fallback 贡献、集中度、去掉最大亏损/最大盈利后的尾部敏感度。
- 输出结论等级：`supports`、`does_not_support`、`uncertain`，避免过度解释小样本。
