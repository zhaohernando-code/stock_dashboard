# 试验田 v2 样本外位置形态与 Rank 入口诊断

本产物是研究型下一跳：只解释方向，不晋级策略，不替换纸面追踪。

## 结论

没有非兜底形态同时满足 holdout 样本量和正收益要求；回撤蓄势 holdout 中位收益为 5.1%，但只有 6 笔。位置形态只能作为软排序特征继续验证。；Rank 入口更像主要矛盾：强势股能进入宽排名，但最终 Top5 覆盖不足

- 这里的“启动前”指 2026-06-01 之前；以上覆盖率是事后诊断，不构成可交易排序回测。
