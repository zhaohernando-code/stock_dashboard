# V3 策略研究结论台账

更新时间：2026-08-17
状态：当前唯一权威研究结论；被删除的逐轮设计、预测明细与一次性模型仅通过 Git 历史追溯。

## 当前结论

- V3 继续作为永久核心基线，外部信息生产权重保持 `lambda=0`；本次清理不改变 V3 信号、买卖建议或账户参数。
- 个人可交易资格仍在任何打分/排序之前执行：普通 A 股主板、决策时点未复权价格不高于 200 元、未开通板块关闭，并逐原因记录剔除。
- 纸面追踪保留三个 V3 角色与一个“外部信息对照”，统一从 2026-07-08 起算。对照只能延长已有持仓，不能由正面新闻独立触发买入。
- 近期失败已把问题定位到“热点机会何时开放、哪些板块获得确认”，而不是继续微调 V3 排名权重或纯股票量价模型。
- 下一轮只有在新增 PIT 板块/全球/事件数据通过质量与时间谱系验收后才启动；不得在当前复用窗口继续扫描阈值。

## 失败方向台账

以下状态均为“停止实现、保留结论”。除外部信息纸面对照外，相关模型不得进入 V3、纸面追踪、live 候选或 runtime。

| 方向 | 观察到的结果 | 失败原因 | 防回归结论 |
|---|---|---|---|
| 外部静态权重、veto、风险闸门、持有期、TopK 重排（Rounds 1–47） | 没有方案同时通过八项非劣化与突出收益门槛 | 方向翻转、整手/现金路径退化、验证覆盖不足 | 不再基于标题情绪或同一数据扫描更多权重 |
| 个人账户持仓延期（Rounds 48–78） | Round 75 全区间 40.32%→46.39%，但优势仅来自一次 603115.SH 延期；留一后消失 | 单事件集中，前向期无新触发 | 仅保留为纸面对照；至少 3 个独立真实前向触发前不得晋级 |
| 稀疏全球风险预算（Round 78） | 在一次冲击期改善回撤，但权重无法由更早独立样本选出 | 单一冲击、事后权重风险 | 至少 3 个独立全球冲击后才允许重新注册 |
| 板块加速反转重排 | 15 个事件中验证段 3 个事件均未改变选择；非零权重全部失败 | 事件检测不等于可执行动作，收益来自继承账户路径 | 不再在复用窗口调板块加速阈值 |
| 新反转股票替换 | 独立 sleeve 全区间亏损 32.29% | 追反弹引入大量普通反抽 | 热点机制不能用通用反转股直接替换 V3 |
| 同股加仓/资金部署加速 | 共享账户有小幅毛收益，但挤掉后续 V3 买单 | 现金路径伪 alpha | 改变后续基线买单的收益不得归因于择时 |
| 现金隔离的 V3 反弹时点 | 子策略为正但显著弱于完整 V3；所有混合权重降低收益 | 稀疏子策略资金闲置、触发子集质量不足 | 不再把正状态当成扩大 V3 暴露的充分条件 |
| 固定提前退出与部分减仓 | 最佳 25% 市场+板块减仓验证 34.92%，低于 V3 35.51% | 经常卖掉随后恢复的持仓；双账未同时改善 | 不再手调退出阈值；若重启只能用新样本的因果剩余持有价值模型 |
| 固定热点二次启动规则 | strict/balanced/broad 分别约 -9.78%/-21.91%/-37.86% | 案例可描述但不能泛化 | 不保留固定规则实现，不用案例命中推翻宽样本失败 |
| Logistic 热点状态重建 | stock-only -4.23%；sector 仅 +1.67%，验证段均 0 笔，胜率 33.33% | 绝对概率漂移、覆盖消失、板块特征无稳定增量 | 当前窗口不得降低门槛；模型代码淘汰 |
| V3-memory 双头恢复 | 5 日均值 -0.22%；仅覆盖生益科技/长电科技 1/2 | 主要漏损发生在现金开关与 Top20 机会入口，模型无法选到门外股票 | V3 身份不能作为热点策略硬门票 |
| 全市场量价回归机会头 | Validation 均值 +0.38%、中位 -0.62%、胜率 40.6%；Final 均值 -0.31% | 能覆盖案例但不能稳定排序 | 保留机会入口数据，不保留回归头 |
| 全市场热点事件分类头 | Validation 均值 -2.34%、胜率 24.7%；案例最好排名 25/69 | 更换尾部标签仍未增加辨别力 | 不再扫描同类股票量价分类目标 |
| Rank5 简单质量、路径质量与执行增强 | 多轮均未同时通过收益、回撤、月份与跳单门禁 | 样本小、边界不稳定；Rank4-only 更稳 | Rank5 继续停用；只保留低成本前向观测，不在旧样本继续搜阈值 |

## 无效结果与有效负结论的区别

- 首次全市场热点运行只有约 3 只股票能在早期形成足够历史，属于数据覆盖无效；它既不证明成功，也不证明失败，原临时产物已删除。
- 复用延伸段、已看过的生益科技/长电科技案例和 outcome-aware 诊断只能解释机制，不能作为样本外晋级证据。
- `lambda=0` 不复现、候选释放现金后新增买单、加仓挤掉后续基线买单、边界月份交叉污染等结果属于真实性失败，不能保留为策略收益。
- 正收益但单触发、零验证交易、低胜率右尾驱动或缺少 PIT 状态谱系，均只保留为研究线索，不保留实现。

## 后续唯一允许的研究路径

1. 先补齐并固化 PIT 板块归属、行业状态、全球状态和高相关官方/新闻事件；每条必须具备 `published_at`、`first_seen_at`、`available_at`、`revision_id` 或明确的不可修订声明。
2. 在保留的 32,028 条全市场机会候选上做增量辨别检验：股票路径仍是主信号，板块只决定行业是否允许竞争，全球状态只控制小型机会头总预算，个股事件只提供有界残差。
3. 正面新闻不得独立创建买入；重大负面官方事件可以关闭候选。外部权重从 0 开始，按静态小权重、规则动态权重、受约束模型逐级晋升。
4. 选择“一标准误以内最小权重”的稳定平台，不选择收益最高的单点；使用新独立时间段，保留双账真实性和完整执行约束。
5. 在渠道覆盖、时间谱系和新样本不足时，正确动作是继续采集纸面证据，而不是创建新模型文件。
