# 策略探索总纲（强制前读）

总纲版本：`2026-09-05.1`

本文件是策略探索的唯一经验入口，也是失败结论与重开条件的权威来源。详细过程只在 Git 历史中追溯，不作为新研究的默认上下文。

## 启动合同

任何选股、持有、退出、权重、热点、板块或外部信息研究，必须先完整阅读本文件。预注册必须写明：

- `exploration_guide_version`：本文件当前版本；
- `prior_direction_overlap`：与下表哪些既有方向重叠；
- `material_novelty`：新增信息、行动空间、独立样本或覆盖中的哪一项发生了实质变化；
- `hypothesis_and_action_space`：要解释的机制，以及策略实际能做什么不同动作；
- `pit_baseline_and_kill_gate`：PIT 口径、精确基线、样本外门禁和失败即停止条件；
- `retention_on_failure`：失败后只保留哪一条结论、哪些独立可复用输入必须留存。

缺少其中任一项，不得开始写策略代码、扫参数或打开结果。仅更换权重、阈值、窗口、正则化、概率门槛或模型形式，不构成新方向。

## 不可动的研究基线

- V3 Rank4-only 是冻结研究对照与当前生产核心，不再预设为永久最优解。依据用户 2026-09-05 的明确授权，可研究底层缺陷、独立简化方案和核心替换；研究失败仍不得改变生产、纸面追踪或 live 候选。
- 个人资格在打分前过滤：普通 A 股主板、决策时点未复权价格不高于 200 元、未开通板块关闭；回测、纸面和 live 共用同一 PIT eligibility snapshot。
- 股票自身量价与质量数据是主信号。正面新闻不能独立买入；全球、板块、个股外部信息分别只能影响总风险、相对排序、个股有界增量。
- 历史研究只能离线回放，且 `available_at <= decision_cutoff`；不允许未来价格、当前静态行业/ST 状态或结果已知后的数据修订回填。
- 晋级必须复现完整 V3 交易账本，并通过顺序样本外、分段稳定性、现金路径、换手、回撤和 one-SE 最小复杂度门禁。

## 已证明值得保留的基础

- 精确 V3 core、个人 eligibility snapshot、未复权日线、申万有效期行业归属；它们是输入，不代表新策略有效。
- External Raw / Normalized / PIT、巨潮与 Tushare 结构化事件、离线哈希 replay；严格行业 first-seen/revision、专业新闻与生产级 vintage 仍不合格。
- 外部信息纸面对照、双账真实性、`lambda=0` 和 one-SE 门禁；对照只延长已有持仓，不由正面新闻创建买入。
- 资产范围、哈希、体积和 claim ceiling 只在 `docs/contracts/STRATEGY_RESEARCH_RETENTION_CONTRACT_2026-08-17.json` 维护，避免在本文件复制。

## 当前开放方向

### 2026-09-05 用户授权的底层审计与有限路线重开

用户明确要求以稳定盈利为目标、允许大胆路线修正并在独立 worktree 实施。此授权允许从架构和测量假设重新审视 V3，不要求继续局限于外部事件增量，也不把旧失败当作禁止纠正底层错误的依据。

- 先审计收益标签的可知时间、训练/验证隔离、真实账户执行、公司行为、资格与成本；可证实的缺陷先复现、定界，再修复。
- 实质新增优先为修正后的证据合同与不同的行动空间；本轮最多两个预注册简化挑战者，禁止遍历参数组合或结果揭晓后改评估区间。
- V3 保留精确冻结对照，旧窗口用于开发或机制诊断；新生成的历史回测不能重新命名为未见样本外。找不到独立窗口时可以冻结候选和前向协议，不能晋级盈利主张。
- 历史事件可基于可验证的首次公开时间和对应原文版本回放，不强制要求本地当年已采集；真实前向仍必须按本地实际可用时间。不能把新下载的最新修订值倒填至旧公告。
- 保持普通可买 A 股主板、决策价不高于200元、日线决策、通常持有不超过30交易日与不盯盘边界。研究授权不等于任何真实资金交易授权。
- 本轮已确认学习研究缺陷：旧训练未实际执行所声称的20日隔离，且缺失5/20日标签会借用10日目标。修复后须按真实标签结果日期成熟准入；旧学习型结果需重验。这不是当前确定性V3亏损的已证实原因。
- 本轮启动合同：`docs/contracts/DAILY_STRATEGY_FOUNDATION_RESEARCH_2026-09-05.json`。研究结论必须包含绝对净收益、同条件对照、风险和可执行性；无合格方案是允许的结论。

### 既有外部信息开放方向（保留为一条候选路线）

在本轮授权重开之前，没有可在同一历史窗口继续拟合的参数型策略方向。该外部路线先准备具备合格时间谱系、数值上下文和相对预期的个股 `surprise/revision` 输入；数据与新独立结果齐备后，才能预注册“个股事件意外残差”。该信号只能在精确 V3 core 之上形成有界增量或重大负面风险闸门，正面事件仍不能独立买入。未满足数据准入前只做渠道验收、PIT 固化和真实前向积累，不写模型、不扫权重。生产外部权重继续为 0。

## 失败后的留存纪律

- 失败探索只在本表合并一条“方法、关键结果、失败机制、重开条件”；删除临时代码、专项测试、预注册、逐日输出、notebook 和派生 artifact。
- 只有与失败模型独立、可复用且有哈希/PIT/claim ceiling 的输入数据可以进入 retention contract；不能因采集成本高就保留无效模型。
- 数据覆盖不足、账本不真实或 PIT 不成立属于“无效试验”，不得写成策略负结论；正收益但单触发、零验证交易、低胜率右尾驱动属于线索，不得保留实现。
- 早期全市场热点运行仅约 3 只股票具备足够历史，属于覆盖无效；生益科技/长电科技等已知案例与复用延伸段只能做机制诊断，不能充当样本外晋级证据。
- 成功挑战者才保留最小生产实现与必要测试。任何结论与本文件冲突时，先更新本文件版本，再开始下一轮。
