# 个人资金与外部信息策略优化尝试（2026-08-10）

署名：hernando_zhao

## 结论摘要

本轮没有替换 V3，也没有把外部信息权重从 `lambda=0` 调高。完成了两个可立即落地的优化，并确认了一个必须继续等待合格数据的边界：

1. 个人资金容量合同可从笼统的 100 万元压力测试收窄到真实可用区间。按既有候选、Top3 和 5% ADV 上限，12 万元档位在全部 957 个有效 pick 上完整成交；连续全量成交边界约为 121,938 元。15 万元开始有 3 个历史 pick 欠成交，均为 603117.SH。
2. Round75 与 V3 纸面追踪的共同起点不一致：它从 2026-08-08 才算真实前向，却被放入从 2026-07-08 起算的同窗对照。该结构会把历史回填带进纸面页并造成不公平比较，因此 Round75 退出 V3 纸面追踪，保留为独立研究产物。
3. 全球行情研究层曾固化 3,132 条记录并参与研究挑战，但当前正式准入层仍为 0 条：没有具备供应商修订号、全篮子覆盖和本地回放授权的导出。因此可以保留既有研究结果，不能把它描述为正式“新闻+全球行情”联合策略，也不能据此提高生产权重。

## Round75 与纸面追踪边界

- 冻结研究合同仍是：外部信息只能延长已有持仓的退出期限，不能独立买入，不能改变 V3。
- V3 纸面追踪的产品合同是所有可比较角色统一从 2026-07-08 起算。Round75 的真实前向起点是 2026-08-08，不能进入同一曲线、收益卡或成交明细。
- 纸面日刷停止为 Round75 生成新订单和账户记录；读模型过滤既有 Round75 记录、计划、账户净值和统计；前端移除 Round75 卡片。
- 已有 `shortpick-round75-shadow-tracking.json`、信号注册表和研究结果不删除，继续作为独立研究证据，但不再拥有“纸面对照组”身份。
- 纸面页只保留现行主策略、稳定盈利前沿、上游元信号三个角色，并共同从 2026-07-08 展示。

## 全球行情与新闻层

现有本地事实分成两层：

- 研究层：3,132 条全球行情记录曾用于多轮历史挑战，结论仍是研究用、非生产用。
- 正式准入层：0 条。Wind 合格导出尚未收到；Tushare/Tiingo 因缺少供应商修订谱系而淘汰；公开来源评审没有找到能同时满足全篮子、修订、许可和离线回放的来源。

因此本轮不重新抓取弱来源、不临时联网回测，也不把既有研究快照升级成正式数据。下一次全球行情正式挑战组只有在合格导出进入 Raw/Silver/PIT 合同后才启动；新闻层同理，摘要可保留，但必须有 `published_at / first_seen_at / available_at / revision_id` 和可回放权利。

## 决策

- V3 继续保持 `lambda=0`，个人资格过滤和既有生产逻辑不变。
- 个人资金的当前已验证容量档采用 120,000 元；更高资金继续作为压力观察，不改选股。
- Round75 继续作为独立研究影子产物，不进入 V3 纸面追踪；纸面页三组统一从 2026-07-08 起算。
- 全球行情正式联合回测仍被合格全窗口导出阻塞；既有研究结果继续保留，不夸大证据等级。

## 局限

容量扫描是成交容量诊断，不是 12 万元账户的独立收益回放。移出 Round75 会减少纸面页的角色数，但恢复了同窗对比的可解释性；其独立研究证据仍被保留。全球行情层的阻塞来自正式数据合同，而不是历史研究记录为零。
