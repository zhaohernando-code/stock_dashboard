# V3 外部信息多轮研究收口（2026-08-08）

## 结论

V3 不是“策略不好”。冻结账户基线在 `2023-09-07` 至 `2026-06-26` 的 511 个信号日上，总收益约 `332.10%`、最大回撤约 `-6.89%`；最后复用观察段 `2025-11-27` 至 `2026-06-26` 收益约 `48.67%`、负收益月份为 `0`。这是一个很强的对照，因此外部挑战者必须证明新增价值，不能因叙事合理就进入 V3。

截至本轮，没有外部方案同时满足八项冻结非劣化指标和“突出优势”门槛。生产建议保持 `lambda=0`，V3、纸面追踪和 live-facing 候选均不改。

## 研究覆盖

研究按静态权重、规则动态权重、受约束学习逐级推进，覆盖：

- 全球风险与行业状态的强弱 veto、层级 veto、稀疏风险闸门；
- 官方负面公告事件的仓位、权重和持有期保护；
- 10/20/30 日动态持有期、提前退出；
- 核心模型与外部模型的残差权重；
- Rank1/Rank2 预算迁移、整手约束、一手约束、资金流增强；
- V3 前 20 候选池外部残差重排；
- V3 前 5 近似同分股的申万 20 日相对强度破同分；
- 只使用已到期历史标签的动态板块有效性门控；
- 第 10/20 名以内的可负担替补扩展。

所有正式轮次保留 `lambda=0`；参数选择使用调参段、验证段和一标准误最小复杂度规则。最后一段已经在先前轮次被多次查看，因此只标为 reused extended readout，不再声称 untouched holdout。

## 最接近但仍不合格的候选

`external_pair_q060_transfer5` 在 Rank1/Rank2 之间迁移 5% 信号预算：

- 调参段收益比 V3 高约 `2.16` 个百分点；
- 验证段高约 `1.17` 个百分点，回撤略有改善；
- 延伸段高约 `0.50` 个百分点，相对收益提升约 `1.03%`，回撤略有改善；
- 但整手取整导致跳单率、跳过信号率和最大暴露均上升，且远未达到 `10%` 相对收益提升。

它是值得保留的研究挑战者，但不是“各维度不劣化且有突出优势”的新策略。

## 被真实性审计否决的假增益

1. 候选改变后释放现金，原本没成交的 V3 股票随后成交，会产生 candidate-only cash-path buys。这是路径副作用，不是外部信号 alpha。
2. 早期官方公告风险闸门看似提升收益；改为按冻结基线实际买入符号约束后，真实触发数为 `0`，原收益来自替补成交路径，结论作废。
3. 第 28 轮首跑的 `lambda=0` 排名没变，但现行执行代码比冻结基线多成交。加入 shadow actual-buy 约束后，NAV 和真实买卖逐笔复现，首跑结果判定为 authenticity-invalid。
4. 早期候选重排只在原 Top3 内进行，无法检验第 4–20 名在回暖期被提升。后续已显式测试 Top20，但受约束模型在调参段显著劣化，仍被拒绝。

## 为什么新闻标题还不够

V3 候选涉及 1,837 只股票，CNINFO 标题资产覆盖 1,833 只；在候选范围内识别到约 20,979 个正负事件。标题信号在调参、验证、延伸三个阶段出现方向翻转：例如“回购/增持/业绩预增”标题既可能代表新增信息，也可能只是已被价格消化的例行披露。没有正文、市场预期和 surprise 基准时，标题情绪不能稳定承载权重。

公开新闻不是“获取不到”，而是高质量、可历史重放、带修订/首次可见时间且可合法长期保存的全窗口数据仍不完整。Tushare `major_news` 可用但当前账户约 30 请求/小时；GDELT 只适合发现，不能作为专业新闻直接特征。下一次值得投入的门槛是：专业新闻试用或公告正文/预期差特征，外加新的独立时间留出段。

## 决策

- 保留 V3 为永久 `lambda=0` 基线。
- 外部层继续作为研究基础设施与风险解释层，不进入 V3、不发布、不启动新的纸面策略。
- 不因单一验证段变好而放宽八项门槛，也不把 deliberate no-order 事后改名来消除跳单失败。
- 下一轮只在新增信息集真正变化时启动：合格专业新闻、正文 surprise、供应商 revision/vintage，或自然积累的新未见纸面时间段。
