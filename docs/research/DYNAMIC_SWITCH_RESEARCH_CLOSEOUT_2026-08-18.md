# 动态策略切换研究收口（2026-08-18）

## 结论

当前不应给 V3 增加热点开关，也不应把任何本轮候选加入纸面追踪。问题首先不在开关，而在可被切换的热点策略本身尚未成立。

- 现有 V1 热点规则先按当日涨幅取 Top40，最终入选股几乎都在涨停附近；可成交样本相对 V3 平均每天落后约 412bp。
- 三类嵌套走步开关都没有稳定通过历史门槛。它们相对固定 50% 热点配置看似更好，只是因为固定热点配置本身很差。
- 新建的尾随学习“再加速”候选平均相对 V3 为 +16.25bp/日，但 95% 区间横跨 -44.99～+79.37bp，2026 上半年为 -78.40bp/日，只在五个半年区间中的三个为正，因此没有资格进入开关研究。
- 学习模型最终重新偏向银行、公用事业等防守股，说明把“识别板块行情”和“选择板块内领涨股”交给一个全市场个股模型，会再次回到原来的防守风格。

## 为什么不是继续调开关

开关只能在两套已经各自有意义的策略之间分配权重。当前热点候选并不具备独立历史价值，继续增加门槛、模型或权重，只会让模型学习“什么时候尽量不要用它”，无法回答“什么时候应该进攻”。

这也解释了此前多轮碰壁：风险闸门、外部残差、市场状态和个股排序都在 V3 周围做局部修补，但缺少一套真正能代表热点/再加速行情的第二策略。

## 已冻结的失败结论

1. 风险与排序残差：动作空间只能减仓或小幅换序，无法捕捉 V3 完全错过的领涨股。
2. 已登记的 regime-adaptive 候选：历史静态收益较好，但并非热点风格；动态时机不稳定，且不如固定 50% 对照。
3. V1 进攻候选：本质是追当日涨停，成交困难且后续收益明显为负。
4. 单阶段机器学习候选：均值略正但区间、分期稳定性不合格，并发生防守风格漂移。

这些方向只保留结论，不进入生产代码或纸面追踪。

## 下一条研究主线

下一阶段改为“两层策略”，不再直接优化开关：

1. 先建立 PIT-safe 的历史板块成员、板块收益、上涨广度、扩散速度和拥挤度快照。
2. 第一层只判断哪些板块正在形成有广度的行情；全球行情和新闻以后也只进入这一层。
3. 第二层只在已确认板块内选择流动性足够、个人可交易、当日未涨停且尚未过热的领涨股。
4. 这套板块+个股候选必须先独立通过嵌套走步历史门槛，之后才允许研究 V3 与它之间的动态权重。
5. 最后才进入未见过的前向影子对照。

当前硬阻塞不是模型复杂度，而是历史板块归属的 PIT 版本链还不够严格；在补齐前，任何板块轮动的“成功”都只能视为探索性结果。

## 数据与口径边界

研究覆盖 2023-09-15 至 2026-06-18；价格使用决策时点未复权收盘价，次日收盘进入、第五个交易日收盘退出，计 10bp 往返成本。仅保留主板 A 股代码前缀，决策价超过 200 元的股票在打分前剔除。所有学习标签必须在重新训练前已经完整兑现。

本轮没有联网、没有修改 V3、没有修改纸面追踪或实盘候选。由于基础历史股票池来自当前仍活跃股票快照，仍存在幸存者偏差；历史 ST/退市状态和严格 PIT 行业归属也尚未完整。
