# Shortpick v3 Sol/Terra 递归探索合同（2026-07-10）

## 目标

使用主会话 `sol` 负责提出优化假设、统一口径和最终裁决；每个独立方向交给 `terra` 子代理做完整历史逐订单实验。
在找到合格候选以前，按“提出方向 -> 并行实验 -> 统一验收 -> 继续提出方向”的顺序递归执行。

合格候选必须同时满足：

1. 与前端现有策略使用同一完整历史窗口和账户合同。
2. 每项核心指标都不劣于前端全部策略在该指标上的最优值，而不是只优于某一条策略。
3. 至少一个重要指标相对当前最优值改善 `>= 10%`；负收益月份减少至少 `1` 个也视为明显突破。
4. 不得通过缩短窗口、修改费用、放宽 20 万资金/100 股整手约束、使用未来数据或硬编码股票和日期通过。

## 固定比较口径

- 信号窗口：`2023-09-07 ~ 2026-06-26`
- 初始资金：`200,000 CNY`
- 资金模式：按当前 NAV 复投
- 交易粒度：逐订单现金账户回放
- 买入：信号日后的下一交易日收盘
- 最小交易单位：`100` 股
- 禁止模式：月度满仓轮动、跨重叠持仓重复使用现金

## 第八至十三轮归因

| 方向族 | 状态 | 结论 |
|---|---|---|
| 当前可复现源的强弱分段与容量联合扫描 | 已拒绝 | 能改善部分收益或跳过率，但无法同时守住九项前沿 |
| 同日 Top20 可买替补 | 部分有效 | 显著降低高价票导致的跳过，但广泛替补会扩大单票暴露 |
| 分段赢家延长、宽止损、动态持有期 | 已拒绝 | 收益厚度或最差月明显劣化，不能进入对照组 |
| 账户回撤控制器、整数手数重配 | 已拒绝 | 现金路径改变后收益和稳定性无法同时过门槛 |
| Rank4-20 替补质量约束 | 有效组件 | 库存 Rank 上限、分差和填充率能减少低质量替补 |

这些轮次把阻塞点收敛为一个组合问题：可买替补能改善执行覆盖，但需要用收盘市值口径的窄暴露控制，
而不是降低原上游质量门槛或添加普适止损。
