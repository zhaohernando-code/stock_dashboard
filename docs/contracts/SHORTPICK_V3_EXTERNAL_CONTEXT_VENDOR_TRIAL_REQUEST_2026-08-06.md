# Short Pick V3 外部信息渠道试用申请包（2026-08-06）

状态：可直接用于询价/试用申请，但尚未向任何供应商发送，也未作采购承诺。

## 统一试用范围

试用目标不是比较收益，而是验证能否构建无未来信息、可离线重复回放的 full713 数据集。申请期应覆盖 `2023-05-01` 至 `2026-05-26`，其中策略信号窗口为 `2023-06-13` 至 `2026-05-26`、共 713 个信号日。每家候选必须提供数据字典、许可条款和一个可重复拉取的历史样本。

## 必答问题

1. 每条记录是否明确提供 `published_at`、`first_seen_at`（可由本地采集产生）、`available_at`、`revision_id`？请给出字段名、时区、精度、空值规则和样例。
2. `available_at` 是否表示客户在当时真正可获取数据的时间，而非事后入库时间或业务生效日期？历史回补、迟到数据和盘后修订如何标记？
3. 修订、撤回、纠错和替换是否保留旧版本？原记录与新版本能否通过稳定 ID 和 `revision_id` 形成完整链路？
4. 是否允许把 Raw 响应、标准化版本和 PIT 快照长期保存在本地，用于订阅期内及订阅结束后的内部历史回测和审计？
5. 是否覆盖完整申请期？历史接口与实时接口的字段、ID、时间语义是否一致？
6. 速率限制、批量导出、SLA、故障补数、历史重发和数据更正通知机制是什么？
7. 实体、证券、行业/板块和跨市场映射的标识体系是什么？标识变更、并购、改名和退市如何处理？
8. 能否对同一冻结查询在两个时间点重复交付，并解释内容哈希变化的原因？

任何候选若不能明确回答四个时间血缘字段，直接终止 PoC，不进入价格谈判或综合评分。

## 分层样本要求

### 官方事实层

- 巨潮资讯、上证信息、深证/深圳证券信息：按冻结事件集提供上交所/深交所公告、风险警示、问询、业绩预告、停复牌及更正/替换样本；必须保留原始文件与消息元数据。
- SEC EDGAR：使用 accession、acceptance datetime、filing/amendment 关系和保守可用延迟；现场请求必须配置真实、可联系的 `User-Agent`，当前项目未保存联系人信息，因此尚未执行在线样本。
- 公司 IR：覆盖 NVDA、AMD、INTC、MU、TSM、ASML、AMAT、LRCX；IR 只能作为公司原始事实候选，不能用网页当前状态回填历史可用时间。

### 全球行情层

- Wind：SPX、IXIC、SOX（或可审计替代指数）、恒生科技、恒生指数、USD/CNH、美国 10 年期国债、WTI；需要可追溯的修订/更正版本和历史回放许可。
- 低成本候选只有在与上述同一字段和许可合同下才可进入；当前 Tushare `index_global` 与 Tiingo EOD 因缺少明确 `revision_id` 已淘汰。

### 专业新闻层

- LSEG 与 RavenPack 使用同一批 136 个官方事实锚点，并提供至少 200 条人工复核样本；评估发布时间、客户可用时间、修订、去重、相关度、新颖度、实体映射、来源质量和冲突处理。
- 正文/摘要/特征的本地留存与订阅后重放权必须分别写明。当前 Tiingo News 与 Tushare `major_news` 因缺少明确 `revision_id` 已淘汰。

## 交付与验收

候选样本进入不可变 Raw 层，随后生成 Normalized（实现 schema 名为 Silver）和 PIT 快照。相同 manifest 的离线重放必须哈希一致，并满足 `available_at <= decision_cutoff`。通过全部硬门禁后才比较纪录性综合分；综合分不能挽救任何硬门禁失败。

本申请包仅准备供应商沟通材料。发送、试用开通、签署许可和付费均需要账户联系人与用户的外部行动授权。
