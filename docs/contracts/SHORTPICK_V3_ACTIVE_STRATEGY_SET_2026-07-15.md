# v3 活跃策略集合合同（2026-07-15）

## 结论

先收敛、再优化。活跃展示和纸面追踪固定为三个不可叠加的角色：

| 角色 | 策略 | 后续用途 |
|---|---|---|
| 优化前沿 | R14 高质量可买替补 + 25% 暴露再平衡 | 新优化必须与其同窗比较并尝试替换它 |
| 独立模型族对照 | 上游元信号稳健缩放 | 检验不同上游信号机制，不作为规则堆叠入口 |
| 前向运行基线 | 现行 14 tranche 分层退出 | 衡量真实前向增益，不再承接新规则 |

## 归档集合

递归上游 Rank 调整、元信号质量分层、三段稳定性、条件化攻击和 15 tranche 低集中度进入归档桶。归档意味着：

- 不生成新的纸面计划单；
- 不出现在活跃历史指标表和纸面策略表；
- 保留已有回放合同、指标、计划历史和成交历史；
- 只有在新的同窗证据证明其能替换三个现有角色之一时，才允许通过新治理决策恢复。

## 防扩张门禁

活跃策略数量上限为 3。任何新策略必须声明被替换的角色，并在同窗口、同费用、同本金、同整手和同执行约束下比较。只增加参数变体、只击败归档策略、或没有独立诊断价值的候选不得进入活跃集合。

后端日刷只初始化并结算三个活跃账户；读模型过滤旧状态中的归档订单和记录；前端再次按活跃 ID 白名单过滤，以防运行时短暂读取旧 JSON。
