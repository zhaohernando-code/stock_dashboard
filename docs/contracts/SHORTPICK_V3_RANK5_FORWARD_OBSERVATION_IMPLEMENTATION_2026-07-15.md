# Rank5 固定前瞻观察窗实施说明

## 结论

Rank5 已进入固定、不可中途调参的真实前瞻观察阶段。当前 R14 规则、活跃策略数量和计划单选择顺序均未改变；这次实现只增加证据采集、成熟度判定、成交关联和看板进度。

## 数据流

1. 日刷读取当天已落库的 v3 candidate-run。
2. 当质量替补策略的原始标的因 `price_too_high_for_slot` 被跳过时，独立评估同日库存 Rank5 是否满足现行基础分差、可选、可买、整手、最小金额和填充率规则。
3. 使用信号日及此前的日收盘数据计算五个 20 日路径特征。Rank4 优先被选中也不会删除 Rank5 影子观察。
4. 观察键由策略、信号日、原始标的、Rank5 标的和库存序号确定，随被选中的 Rank5 计划单进入买入、持仓和卖出记录。
5. 影子收益在完整 20 个后续交易日出现前保持为空；成熟后按候选标的首个信号后收盘到第 20 个后续收盘计算，并在相同入场、退出日期对齐沪深 300。
6. 纸面状态保存逐条观察和冻结门槛进度；摘要接口只返回进度，完整接口保留逐条行。

## 防泄漏与失败关闭

- `synchronized_start_backfill` 不进入证据样本。
- 信号日前路径不足 20 个收益观测时，该行排除且数据质量门禁阻断。
- 缺失/重复观察键或未成熟行提前出现未来收益时，整体状态为 `blocked_data_quality`。
- 观察期间 `active_rank5_quality_policy` 固定为空；达到门槛也不会自动改阈值、添加策略或改计划单。

## 冻结门槛

- 重开研究：80 个成熟影子样本、6 个成熟信号月份、120 个日历天，且数据质量全部通过。
- 讨论推广的最低前向证据：在重开研究门槛之上，至少 20 个 Rank5 实际成交并闭环、12 个信号月份、365 个日历天。
- 达到重开门槛后，必须先冻结下一份评估设计，才能读取成熟结果并开展分析。
